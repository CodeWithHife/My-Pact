# MyPact — Uncompromising Student Accountability

MyPact is an uncompromising student productivity and accountability platform combining AI syllabus parsing with strict, interactive verification alarms and escalating consequences to eliminate procrastination and enforce academic discipline.

## Built With

- [Next.js](https://nextjs.org) (App Router, React 19, TypeScript)
- [Tailwind CSS](https://tailwindcss.com)
- [Font Awesome](https://fontawesome.com)

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
